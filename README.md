# Strand Config

Configuração de badges do Strand.

- `badge/badges.json`: configuração completa com 55 filtros.
- `badge/logo/`: cinco logos Dolby em PNG com fundo transparente, símbolos e fontes pretos, alinhados à altura de 124 px.

Importar no Strand:

https://raw.githubusercontent.com/mvpinheiiro/strand-config/main/badge/badges.json

A configuração mantém os filtros e as expressões regulares anteriores; foram atualizadas as URLs das cinco imagens Dolby. Os outros endereços de imagem mantêm a versão corrigida já existente.
